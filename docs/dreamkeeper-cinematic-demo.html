DreamKeeper
01 / Problem

The agent can reason. The chain only settles.

A hallucinated address, a prompt injection, or a dropped network packet can become an irreversible transaction. DreamKeeper removes the model from the trust boundary.

A Daydreams agent gets real execution, without getting raw trust.

DreamKeeper wires transfers, contract calls, check-and-execute flows, protocol actions, and Tempo payments into KeeperHub. The permission layer is code, not vibes.
